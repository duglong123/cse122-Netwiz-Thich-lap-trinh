# NetWiz – Hệ thống hỗ trợ giảng dạy và học tập môn Mạng máy tính

**NetWiz (Project: Superhero)** là hệ thống hỗ trợ giảng dạy và học tập môn **Mạng máy tính**, kết hợp quản lý học liệu phân tầng với Gamification chiến thuật cho 4 nhóm người dùng: **Guest, Student, Lecturer, Admin**.

## Các phiên bản UI/UX Demo trong `Design/`

- **Demo V1** ([`Design/demo-v1/`](./Design/demo-v1)): Giao diện Dark Command Cobalt với Sidebar điều hướng đầy đủ và dashboard đa khối.
- **Demo V2** ([`Design/demo-v2/`](./Design/demo-v2)): Giao diện Focus Studio tối giản widget, tăng độ tương phản bảo vệ mắt khi học lâu, hỗ trợ chuyển đổi chế độ **Sáng (Warm Paper) / Tối (Warm Charcoal)**.

### Chạy Demo V1

```bash
cd Design/demo-v1
npm.cmd install
npm.cmd run dev
```

### Chạy Demo V2

```bash
cd Design/demo-v2
npm.cmd install
npm.cmd run dev -- --port 5174
```
